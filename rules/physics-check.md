# 物理正确性校验（强制，不可跳过）

教学视频讲错一道题 = 整条视频作废。以下规则按题的类型执行。

## 规则 1：答案不能只靠推理

- **能用数值仿真验证的题（力学为主）必须仿真**：建运动方程积分，把"每个选项的对错"翻译成仿真能回答的问题
  - 例：选项说"最右端时物块速度为零" → 仿真打印该时刻 v物
  - 例：选项说"摩擦力不变" → 仿真打印 f(t) 序列
- **不能仿真的题（电磁感应、几何光学、原子物理等）**：从两个独立角度推导（如能量法 + 动力学法），结论一致才可用

## 规则 2：仿真输出"讲解锚点"清单

跑完仿真先打印这些量并人工核对合理性（数量级、单位、符号）：

- 关键时刻：第一次共速、端点/转折、最终稳定状态
- 关键取值：这些时刻各物体的 v / a / f
- 极值：相对位移范围、能量分配

锚点要写进 `motion.json` 的 `events` 字段，场景组件直接引用，**禁止在组件里手写物理数值**。

## 规则 3：参数选择服务于讲解

- 仿真参数（质量、μ、k 等）可以不是原题数值，但必须：保持模型的物理结构不变；让动画时间尺度适合观看（首个关键事件在 0.3~0.5s 内发生、全程 5~15s）
- 参数选好后跑一遍参数扫描（多组参数下结论不变），确认讲解逻辑对参数不敏感——避免"只在特殊参数下成立"的错误讲解

## 规则 4：常见易错点自查

- 速度为零 ≠ 加速度为零（释放瞬间类问题）
- 摩擦力方向由**相对运动**决定，不是由运动方向决定
- 静摩擦与滑动摩擦的切换条件（所需静摩擦是否超过最大静摩擦）
- 能量守恒：摩擦生热 = 机械能损失 = f × 相对路程
- 竖直方向约束、绳/杆突变等经典陷阱（按题型补充）

## 规则 5：讲解深度分级

根据受众（题目所在年级）调整：
- 初中：定性为主，公式只给 F=ma 级别
- 高中基础：给公式和图像，少推导
- 高中强化/高考：给出推导链（如 a = μg 不变的完整论证）

拿不准时按"高中基础"处理，并在总结段给方法模型（三步法之类）。
