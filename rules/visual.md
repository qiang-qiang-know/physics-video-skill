# 视觉规范

## 箭头/颜色语义（全片一致，不许换）

| 含义 | 颜色 | 色值 |
|---|---|---|
| 弹力/支持力类 | 蓝 | `C.blue #1F6FEB` |
| 摩擦力 | 橙 | `C.orange #F2711C` |
| 重力 | 灰 | `C.gray #93A1B1` |
| 速度 | 绿 | `C.green #17A05A` |
| 加速度 | 紫 | `C.purple #7C5CFF` |
| 错误/禁用 | 红 | `C.red #DC3545` |

- 浅色底 `C.bg #F4F6FA` + 白卡片 + 深墨字 `C.ink #16202C`
- 虚线箭头 = 该力/量尚未出现或不存在的对照
- 每个物体一套 FBD（`components/FBD`），标题注明"木箱（M）"等

## 字号基准（1920×1080 横版）

| 元素 | 字号 |
|---|---|
| 题干正文 | 33~37 |
| 选项行 | 27~29 |
| 卡片标题 | 23~27 |
| 公式结论条 | 30~34 |
| 字幕（Karaoke） | 37 |
| 顶部章节标题 | 32 |
| FBD 箭头标签 | 21 |

竖版（1080×1920）**不是横版缩放**，是重新排版：正文 36~46、字幕 46、公式条 33+；SVG 场景文字用 `k` 放大系数（1.35~1.6）。

**缩放禁令**：1920→1080 只有 0.56 倍，42px 正文缩小到 23px，手机上必然发糊（真实踩坑）。模板已移除缩放路径，未写专用竖屏组件的段落由 `scenes/DyGeneric.tsx` 以原生大字要点卡兜底。

竖版三种做法，按优先级：
1. **专用竖屏组件**（`SCENES_DY[segId]`）：图文/动画类段落的最佳解，重新排 1080×1920
2. **DyGeneric 兜底**：纯讲解段落够用——逐条要点卡，当前句高亮
3. 局部缩放：只允许对**单个 SVG 图形**（不含正文）缩放，且缩放后字号折算不得低于 30px

## 平台安全区

- **横版**：底部 120px 给进度条/字幕，其余自由
- **竖版（抖音）**：
  - 顶部 250px、右侧 100px：避开状态栏与点赞/评论/分享栏
  - 底部 450px：完全留白（文案、账号名 UI）
  - 字幕放画面中心带（y ≈ 1350~1550）
  - 每段顶部加一条「本节关键」要点条（竖屏用户随时划入，需要立即知道在讲什么）

## 通用组件速查（components/）

- `ui.tsx`：`Card`（白卡）、`Chip`（标签胶囊）、`Verdict`（✓/✗ 结论条）
- `FBD.tsx`：受力分析图。props：`forces: {label, dir, color, value?, appear?, len?}[]`，`appear` 控制 0..1 出现动画，`body` 可塞额外 SVG
- `VtGraph.tsx`：通用 v-t 图。props：`series: {key,label,color}[]`（key 对应 motion.json samples 的字段）、`marks`（竖虚线标记，`dotOn` 指明哪些曲线画圈）、`shade`（高亮区间）、`tNow` 控制曲线绘制进度。坐标轴文字有 `k` 放大系数
- `primitives.tsx`：SVG 基元——`Arrow`、`Block`（物块）、`Ground`（地面+阴影线）、`Wall`、`Spring`（弹簧折线）、`Incline`（斜面）。用它们拼本题场景，别从零画
- `Subtitle.tsx`：卡拉OK字幕 + 进度条（自动运行，别动）

## 布局惯例（横版）

- 内容区：x ∈ [110, 1810]，顶部栏下从 y=104 开始
- 题目卡在上，画面/图表卡在下或右
- 结论条（深色 `#0F1B2B` 底白字）是每段的收尾记忆点
- 动画时长：入场 10~16 帧，结论条出现 16 帧

## 动画可信度

- 运动动画必须由 motion.json 驱动（`sampleAt(t)`），禁止手写位置公式
- 读数面板（t / v / f 方向 / a）实时显示当前采样值，观众能"看着数据理解"
- 能量类讲解用实时条形图（机械能/内能/动能），数据同样来自仿真
